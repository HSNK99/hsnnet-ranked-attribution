# Data Availability

BOSSBase 1.01 and BOWS2 images are not redistributed in this repository.
The repository provides pair identifiers, split evidence, calibration artifacts,
response vectors, per-image predictions, and table-regeneration outputs. The ten
detector checkpoints are distributed through GitHub Release `v1.0.0`
(https://github.com/HSNK99/hsnnet-ranked-attribution/releases/tag/v1.0.0). Dataset paths must be supplied locally through
`configs/paths.example.json`.
